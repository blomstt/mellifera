# Contributing

Thanks for wanting to help. Mellifera is dual-licensed (AGPL-3.0 and a commercial licence,
see the README), so every contribution has to be licensable both ways. That needs a
contributor licence agreement, and it isn't ready yet.

Until it is:

- **Issues are welcome:** bugs (with what you ran, on what, and what happened), ideas and
  questions.
- **Pull requests can't be merged yet.** If you have a fix, describe it in an issue; small
  fixes may be redone from the description.

Once the agreement is ready, a bot will ask you to sign it on your first pull request, and
this file will say how to build, run the tests (`tests/run.sh`) and send changes.
